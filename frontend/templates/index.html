⚙️ 기본 헤더 프로파일

      
    

    

      

        여기 설정한 헤더는 요청에 해당 헤더가 없을 때만 보충됩니다(사용자 지정/붙여넣은 헤더는 절대 덮지 않음).
        URL 바의 기본헤더 체크를 끄면 이 프로파일을 무시하고 raw 그대로 전송합니다.
      

      

        
        
      

    

    

      
      
      
    

  







  

    

      
📋 요청 붙여넣기 Raw HTTP / cURL / wget / HAR

      
    

    

      

        
        
        
        

          또는 HAR 파일:
          
          (DevTools → Network → Save all as HAR — SPA의 실제 API를 한 번에 가져옵니다)
        

      

      

        
        

      

      

        ℹ️ 명령을 서버에서 실행하지 않고 파싱만 합니다. URL·헤더·바디·쿼리가 폼에 채워지며, 이후 페이로드 주입·전송을 이어서 할 수 있습니다.
      

      

        
        
        Host 헤더의 서버에 연결합니다. 요청줄과 중복 헤더는 편집한 그대로 보냅니다.
